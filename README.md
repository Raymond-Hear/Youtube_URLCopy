# YouTube 链接分批复制

一个本地运行的 Microsoft Edge 扩展。它会直接在 YouTube 频道、播放列表和搜索结果页右上角放置链接复制工具，不需要打开额外页面，也不会滚动当前页面。

## 1.7 本地预览版

- 新增快捷键 `Alt + Shift + Y`，无需移动鼠标即可触发页面红色复制按钮；
- 快捷键复用同一套来源、批次和待确认状态，不会造成重复复制或另起进度；
- 开启“复制前选择”时，第一次按快捷键收集并展开清单，确认选择后再次按快捷键执行复制；
- 快捷键只在当前活动的 YouTube 支持页面生效，不增加扩展权限；
- 如快捷键与其他软件冲突，可在 `edge://extensions/shortcuts` 中重新设置。

## 1.6 本地预览版

- 已复制记录现在可以分别导出为 TXT 或 CSV；
- TXT 沿用当前“仅链接 / 标题＋链接”格式，适合直接粘贴到其他工具；
- CSV 固定包含“序号、标题、视频ID、链接”四列，适合用 Excel、飞书表格等继续整理；
- CSV 使用带 BOM 的 UTF-8 编码，Windows 下直接打开中文不会乱码；
- 复制前取消的视频不会进入 TXT 或 CSV 导出。

## 1.5 本地预览版

- 新增可选的“复制前选择”开关，默认关闭，原来的一键复制流程不变；
- 开启后，扩展会先收集下一批视频并展开清单，默认全选，可以逐条取消不需要的视频；
- 点击“复制已选 N 条”后，剪贴板、上一批预览和 TXT 导出只包含勾选的视频；
- 取消勾选的视频会记为“已跳过”，后续批次不会再次出现；
- 尚未确认的选择清单会保存在浏览器本地，刷新页面或重新打开后仍可继续确认。

## 1.4 本地预览版

- 复制格式可选“仅链接”或“标题＋链接”，并记住上次选择；
- “标题＋链接”格式中，每个视频先输出标题，下一行输出标准链接，视频之间保留一个空行；
- 上一批预览、重新复制和 TXT 导出都会使用当前选择的格式；
- 新复制的批次会在本地保存标题，旧版本中没有标题的记录会自动退回“仅链接”，不会制造假标题；
- 标题只从 YouTube 当前页面数据读取并保存在浏览器本地，不会上传。

## 1.3 本地预览版

- `1.3.1` 新增“导出已复制 N 条”，可把当前频道、播放列表或搜索条件下已经复制过的全部链接保存为 TXT；
- 导出文件沿用每条链接之间空一行的格式，并在文件名中标注来源、数量和日期；
- 每批数量可以选择 `10 / 25 / 50`，扩展会记住上次选择；
- 改变每批数量不会清空当前来源的进度，例如复制完 50 条后切换到 10 条，下一批就是 51–60；
- 新增“查看上一批”，可以在页面工具里直接检查刚复制的标准链接；
- 预览内容与剪贴板格式一致，每条链接之间保留一个空行；
- 本阶段只保存在本地分支，尚未推送到远端仓库。

## 1.2.1 版

- 新增“视频 + 复制”插件图标，并为 Edge 工具栏、扩展管理页和安装界面提供完整尺寸；
- `assets/icon.svg` 是可继续编辑的矢量源文件，清单使用从它导出的 PNG 图标。

## 1.2 版体验优化

- 保存 YouTube 分页游标和本页剩余链接，下一批直接从上次位置继续；
- 分页游标失效时自动从头重新定位，并排除已经复制的链接；
- 显示明确的批次与范围，例如“第 2 批：51–100”；
- 支持“重新复制上一批”，不会推进当前进度；
- 页面面板可以折叠成“链接／50 · 已复制 N 条”的小胶囊，并记住折叠状态；
- 完整数据读取失败时，可以降级复制当前页面已经显示的普通视频链接；
- 到达末尾时直接显示“全部完成 · 共 N 条”。

## 本次修复

1.0 版通过非活动后台标签滚动 YouTube 页面。由于 YouTube 会限制后台标签的懒加载，部分频道只能读到最初的 3 条视频。

1.1 版已经移除这条采集路径：

- 页面内直接显示复制按钮；
- 从频道首页自动定位该频道的 `/videos` 数据；
- 读取 YouTube 页面初始数据和 continuation 分页；
- 不创建临时标签，不切换页面，也不依赖滚动懒加载；
- 点击浏览器工具栏图标，也会触发页面里的同一个复制动作。

## 安装或更新到 Edge

1. 在 Edge 地址栏打开 `edge://extensions/`。
2. 打开页面左侧的“开发人员模式”。
3. 首次安装时点击“加载解压缩的扩展”，选择这个项目文件夹（里面可以直接看到 `manifest.json`）。
4. 如果已经安装过旧版，点击扩展卡片上的“重新加载”。
5. **重新加载扩展后，还要刷新已经打开的 YouTube 页面**，页面按钮才会注入。

扩展卡片的版本号应显示为 `1.7.0`，并显示红色“视频 + 复制”图标。

## 使用方法

1. 打开以下任意一种桌面版 YouTube 页面：
   - 频道首页或频道内的任意页面；
   - 播放列表；
   - 搜索结果页。
2. 选择“仅链接”或“标题＋链接”。
3. 选择每批 `10`、`25` 或 `50` 条。
4. 如需排除个别视频，打开“复制前选择”；不打开时仍是一键复制。
5. 点击红色复制按钮。
6. 若开启了“复制前选择”，取消不需要的视频，再点击“复制已选 N 条”；否则读取完成后会自动写入剪贴板。
7. 再次点击下一批按钮，获得后续内容且不会与上一批重复。
8. 点击“查看上一批”可以直接核对结果；如果剪贴板内容被覆盖，可以点击“重新复制上一批”。
9. 复制多批后，可点击“导出 TXT”保存当前复制格式，或点击“导出 CSV”保存包含标题、视频 ID 和链接的表格清单。

也可以点击浏览器工具栏中的扩展图标，或按 `Alt + Shift + Y`，效果与点击页面按钮相同。

复制结果统一为：

```text
https://www.youtube.com/watch?v=_GPSfzoVvC4

https://www.youtube.com/watch?v=_SpyH8wTA-4
```

## 批次与恢复

- 每个频道、播放列表和搜索条件分别保存进度。
- 只有成功写入剪贴板后，当前批次才会计为已复制。
- 页面刷新或中途关闭时，尚未确认的批次不会跳过；再次点击会重试复制。
- “重新开始”只清除当前页面对应来源的复制进度。
- 折叠状态属于工具界面偏好，不会影响任何频道的复制进度。
- 完整读取失败时，“复制当前可见”只复制页面 DOM 中已经加载且尚未复制的链接。

## 过滤规则与限制

- 只输出 `https://www.youtube.com/watch?v=视频ID`，删除播放列表、序号、追踪和时间参数。
- 排除 Shorts、正在直播和预约直播。
- 已结束的直播回放只能依据 YouTube 数据中的标记尽量排除；由于扩展不使用 YouTube Data API Key，无法保证所有语言和页面版本下都能百分之百识别。
- 首版仅支持 `www.youtube.com` 桌面网页，不支持移动版、YouTube Music 或嵌入播放器。
- 此扩展使用 YouTube 网页自身的公开页面数据和分页令牌。YouTube 改变页面数据结构后，可能需要更新解析规则。

## 隐私

扩展没有服务器，不需要账号或 API Key。视频链接、页面来源和复制进度只在浏览器本地处理，不会上传。

## 开发检查

需要 Node.js 18 或更高版本：

```powershell
npm test
npm run test:ui
npm run check
```

`test:ui` 会用本机 Edge 打开完全本地的模拟页面，验证批次选择、逐条取消、剪贴板结果、上一批预览和折叠状态，并把截图保存到被 Git 忽略的 `.artifacts` 文件夹。
