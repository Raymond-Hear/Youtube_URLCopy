# 多平台视频链接分批复制

[English](README.en.md) · 简体中文

![License](https://img.shields.io/badge/License-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-2.0.0-green.svg)

一个本地运行的 Microsoft Edge 扩展。它会直接在 YouTube、B站、抖音和小红书页面右上角放置链接复制工具，支持分批复制、复制前选择、标题＋链接、TXT/CSV 导出与快捷键。

## 2.0 本地预览版

- 新增 B站、抖音和小红书支持，原有 YouTube 功能保持不变；
- 四个平台分别保存来源和批次进度，互不混用；
- B站统一输出无追踪参数的 `https://www.bilibili.com/video/BV...`；
- 抖音统一输出 `https://www.douyin.com/video/数字ID`；
- 小红书只识别带播放标记的视频笔记，不会把普通图文笔记混入清单；
- 小红书会保留页面提供的 `xsec_token` 和来源参数，因为实测删除后部分视频无法打开；
- B站、抖音和小红书会在读取时临时滚动当前列表加载更多内容，结束后自动回到原位置；
- 三个平台都可以继续使用每批 `10 / 25 / 50`、复制前选择、TXT/CSV 导出和 `Alt + Shift + Y` 快捷键。

### 当前支持页面

- YouTube：频道、播放列表、搜索结果；
- B站：UP 主空间、搜索结果、热门或分区列表、单个视频页；
- 抖音：博主主页、搜索结果、精选或推荐列表、单个视频页；
- 小红书：博主主页、搜索结果、发现页、单个视频笔记页。

## 已有功能

- 复制格式可选“仅链接”或“标题＋链接”；
- 每批数量可选 `10 / 25 / 50`，并记住上次选择；
- 可选“复制前选择”，逐条取消不需要的视频；
- 取消的视频会记为已跳过，后续批次不会再次出现；
- 尚未确认的选择会保存在本地，刷新后仍可继续；
- 支持查看和重新复制上一批；
- 支持导出 TXT 或带 UTF-8 BOM 的 CSV；
- 每个来源分别保存进度，只有剪贴板写入成功后才推进批次；
- 快捷键 `Alt + Shift + Y` 与页面红色按钮使用同一套复制流程。

## 安装或更新到 Edge

1. 在 Edge 地址栏打开 `edge://extensions/`。
2. 打开页面左侧的“开发人员模式”。
3. 首次安装时点击“加载解压缩的扩展”，选择本项目文件夹。
4. 如果已经安装旧版，点击扩展卡片上的“重新加载”。
5. 刷新已经打开的平台页面，让新版页面按钮重新注入。

扩展卡片的版本号应显示为 `2.0.0`，名称应显示为“多平台视频链接分批复制”。首次更新到 2.0 时，Edge 可能会提示确认新增的 B站、抖音和小红书网页访问范围。

## 使用方法

1. 打开上方“当前支持页面”中的任意桌面版页面。
2. 选择“仅链接”或“标题＋链接”。
3. 选择每批 `10`、`25` 或 `50` 条。
4. 如需排除个别视频，打开“复制前选择”；不打开时仍是一键复制。
5. 点击页面右上角的红色复制按钮。
6. 若开启了“复制前选择”，取消不需要的视频，再点击“复制已选 N 条”。
7. 再次点击下一批按钮，获得后续内容且不会与上一批重复。
8. 如剪贴板内容被覆盖，可点击“重新复制上一批”。
9. 点击“导出 TXT”或“导出 CSV”，保存当前来源的完整已复制清单。

也可以点击浏览器工具栏中的扩展图标，或按 `Alt + Shift + Y`，效果与点击页面按钮相同。快捷键冲突时可在 `edge://extensions/shortcuts` 中修改。

链接之间统一保留一个空行，例如：

```text
https://www.youtube.com/watch?v=_GPSfzoVvC4

https://www.bilibili.com/video/BV17f421S7YF

https://www.douyin.com/video/7606433195454163429
```

## 批次与恢复

- 每个平台、博主主页、列表和搜索条件分别保存进度。
- 只有成功写入剪贴板后，当前批次才会计为已复制。
- 页面刷新或中途关闭时，尚未确认的批次不会跳过。
- “重新开始”只清除当前页面对应来源的复制进度。
- 完整读取失败时，“复制当前可见”只复制页面中已经加载且尚未复制的链接。

## 平台规则与限制

- YouTube 只输出标准 `watch?v=` 地址，并排除 Shorts、正在直播和预约直播。
- B站和抖音删除列表、来源与追踪参数，只保留标准视频地址。
- 小红书保留打开视频所需的页面访问参数；这类参数由平台生成，过期后可能需要回到原列表重新获取。
- 小红书根据页面播放标记筛选视频；平台页面结构变化时，可能需要更新识别规则。
- 已结束的 YouTube 直播回放只能依据页面标记尽量排除，无法保证所有页面版本下百分之百识别。
- 仅支持四个平台的桌面网页版，不支持移动版、客户端内嵌页、YouTube Music 或嵌入播放器。
- 扩展使用各平台页面中已经提供的数据（如 YouTube 页面公开的 innerTube 分页接口），无需开发者密钥。

## 隐私

扩展没有服务器，不需要 API Key。视频链接、页面来源和复制进度只在浏览器本地处理，不会上传，也不会进行点赞、关注、评论或发布操作。

## 开发检查

需要 Node.js 18 或更高版本：

```powershell
npm test
npm run test:ui
npm run check
```

`test:ui` 会用本机 Edge 打开完全本地的四平台模拟页面，验证平台筛选、批次选择、逐条取消、剪贴板、CSV 导出和折叠状态，并把截图保存到被 Git 忽略的 `.artifacts` 文件夹。
